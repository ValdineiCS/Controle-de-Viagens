# 🧭 Controle de Viagens

Um sistema simples e moderno para **gerenciar viagens**, feito com **HTML, CSS e JavaScript puro**.  
Permite cadastrar rotas, listar viagens, buscar registros e visualizar um **gráfico interativo de custos** com o Chart.js.

---

## 🚀 Funcionalidades

✅ **Cadastro de Viagens**  
- Informa origem, destino, distância e custo.  
- Armazena tudo no `localStorage` (sem necessidade de backend).  

✅ **Listagem e Busca**  
- Exibe todas as viagens registradas.  
- Possui busca dinâmica por origem ou destino.  
- Permite excluir viagens individualmente.  

✅ **Visualização em Gráfico**  
- Mostra o custo total de cada rota com **Chart.js**.  
- Atualiza automaticamente conforme os dados salvos.  

✅ **Interface Responsiva**  
- Totalmente adaptável a telas de **celulares, tablets e desktops**.  
- Tema escuro inspirado em dashboards profissionais.  

---

## 🧱 Tecnologias Utilizadas

- **HTML5** — estrutura e semântica  
- **CSS3** — layout responsivo e tema escuro  
- **JavaScript (ES6)** — lógica principal e manipulação do DOM  
- **Chart.js** — exibição dos gráficos de custo  
- **LocalStorage API** — armazenamento local dos dados

---

## 🧠 Conceitos Praticados

- Manipulação do DOM  
- Estruturas de repetição e condicionais  
- Criação e leitura de arrays e objetos  
- Persistência de dados no `localStorage`  
- Consumo e atualização de gráficos dinâmicos  
- Boas práticas de design responsivo
